ChefTech: Complete Restaurant POS & Online Ordering System

The enterprise-grade, offline-first restaurant management solution built on React 19, TypeScript, Dexie IndexedDB, Tailwind CSS, and Supabase Real-Time Backend.

Release Date: November 2026

1. Overview & Architecture

ChefTech is a modern, high-performance restaurant software bundle designed for dine-in restaurants, fast food cafes, pizzerias, cloud kitchens, and takeaway food chains. It pairs a lightning-fast, offline-capable Point of Sale terminal with an elegant customer-facing online ordering web app.

🚀 Offline-First POS

Operates 100% locally with Dexie IndexedDB. If the internet drops, your cashiers continue taking orders, printing tickets, and completing shifts seamlessly. Auto-syncs when reconnected.

🖨️ Multi-Interface Printing

Direct ESC/POS receipt generation supporting Web Bluetooth (BLE), USB Cable, Serial COM Port, and Network LAN/Wi-Fi (58mm & 80mm). Zero 3rd-party print drivers required!

⚡ Real-Time Online Ordering

Orders placed on the website stream instantly to the POS with an audible chime alert. Customers can track live preparation and delivery status in real-time.

🔐 Bank-Grade Security

Zero default passwords. Passwords hashed with PBKDF2-SHA256 (100,000 iterations). 5-attempt brute-force lockout, HMAC session validation, and Owner PIN protection.

🌍 Global Ready

Built-in currency selector supporting USD ($), EUR (€), GBP (£), PKR (Rs), INR (₹), AED, SAR, CAD, AUD, and custom currencies. Configurable receipt header and addresses.

🛡️ Server-Side Edge Functions

Zero client-side cart manipulation. Order totals, coupon discounts, and loyalty balance redemptions are strictly verified server-side on Supabase Edge Functions.

4. Zero-Config Quick Start (Local Demo)

ChefTech can be evaluated locally immediately without setting up any cloud backend. The POS terminal includes a fully functional Local Offline Mode that saves data in your browser's IndexedDB.

  1. 1

    Start the POS Terminal

    Open your command line in the cheftech-pos directory:

    cd cheftech-pos
npm install
npm run dev

    Open http://localhost:5173 in Google Chrome or Microsoft Edge.

  2. 2

    Perform First-Time Admin Setup

    ChefTech does not ship with insecure default passwords. On your very first visit, the setup wizard will prompt you to:

    • Enter your Master Admin username (e.g. admin)
    • Create a strong password (hashed with PBKDF2-SHA256, 100k rounds)
    • Set a 4 to 8-digit numeric Owner PIN (e.g. 1234) used to authorize discounts, stock edits, and financial reports.
  3. 3

    Start the Online Ordering Website

    The website is pure static HTML/JS. You can run it with any static server or VS Code Live Server:

    cd cheftech-website
npx serve .

    Open http://localhost:3000 to browse the digital menu.

5. Supabase Cloud Backend Setup

Connecting ChefTech to Supabase enables multi-device POS synchronization, real-time website ordering, automated order alerts, and secure cloud backups.

Free Tier Friendly: ChefTech is fully compatible with Supabase's generous Free Tier (500MB database, 50,000 monthly active users, 500,000 Edge Function invocations).
  1. 1

    Create a Supabase Project

    Log into supabase.com, click "New Project", choose an organization, project name (e.g. cheftech-live), a secure database password, and your nearest geographic region.

  2. 2

    Execute the Database Migration

    In your Supabase project dashboard, navigate to SQL Editor → New Query. Open the file:

    cheftech-website/supabase/migrations/20261108000000_initial_schema_and_rls.sql

    Copy its full content, paste it into the SQL Editor, and click "Run". This script will:

    • Create all core tables: menu_items, categories, online_orders, order_items, coupons, loyalty_members, inventory, sales.
    • Apply rigorous Row Level Security (RLS) policies so public users can only read active dishes and track their own orders.
    • Insert starter menu categories and delicious sample dishes.
  3. 3

    Deploy the 4 Supabase Edge Functions

    Using the Supabase CLI, deploy the 4 secure Edge Functions located in cheftech-website/supabase/functions/:

    # Login to your Supabase CLI
supabase login

# Link your local repo to your Supabase project
supabase link --project-ref YOUR_PROJECT_REF

# Deploy the 4 functions
supabase functions deploy place-order
supabase functions deploy consume-coupon
supabase functions deploy issue-loyalty
supabase functions deploy track-order
    Security Benefit: Because calculations happen inside place-order, customers cannot inspect element and modify dish prices or bypass minimum delivery totals!
  4. 4

    Obtain Your API Credentials

    In the Supabase Dashboard, go to Project Settings → API. Copy two values:

    • Project URL (e.g. https://abcdefghijklm.supabase.co)
    • anon / public key (starts with eyJhbGci...)

6. ChefTech POS In-Depth Manual

6.1 Connecting the POS Terminal to the Cloud

In the POS top bar, click the Cloud Sync icon (or go to Admin → Cloud Sync). Enter your Supabase Project URL and Anon Public Key, then click "Connect & Sync".

ChefTech immediately downloads your online menu and begins listening to real-time incoming orders via Supabase Realtime channels!

6.2 Cashier Shifts & Opening Cash

ChefTech enforces proper cash control. Before taking orders at the beginning of a shift, cashiers are prompted to enter their Opening Float Cash (e.g. Rs 5,000 / $50.00).

  • All cash sales automatically increment the drawer balance.
  • Cash refunds and paid-out expenses decrement the drawer balance.
  • At the end of the shift, click "Shift Summary / End Shift" to review the expected cash versus counted cash, generate a detailed Z-Report, and print the shift closing receipt.

6.3 Order Processing Flow

ChefTech supports 3 distinct dining workflows:

🍽️ Dine-In

Assign table numbers (T1 through T12 or custom). Print kitchen order tickets (KOT) directly to the kitchen line before taking payment.

🥡 Takeaway / Walk-in

Quick barcode scanning or category grid tapping. Rapid checkout with one-touch Cash, Card, or split payment calculation.

🛵 Home Delivery

Instant customer lookup by phone number. Auto-populates delivery address and loyalty reward balance. Enforces configurable minimum delivery order.

6.4 ESC/POS Thermal Printers

ChefTech features direct ESC/POS generation for crisp, professional thermal receipts without standard browser print headers/footers:

  • Bluetooth (BLE): Connect wirelessly to handheld 58mm/80mm Bluetooth receipt printers on Chrome desktop, Android tablets, or Chromebooks.
  • USB Cable: Plug-and-play USB thermal printers via the WebUSB standard.
  • Serial / COM Port: Connect POS station receipt printers via COM1, COM2, etc., with selectable baud rate (9600 to 115200).
  • LAN / Wi-Fi Network: Direct raw socket or HTTP relay to network IP printers in kitchen or bar stations.
  • Auto-Print: Enable "Print automatically when sale is completed" for zero-click operation.
  • Kitchen Ticket: Optional kitchen order slip printed above the customer bill.

6.5 Currency & Receipt Customization

In Printer & Receipt Settings, customize your store's branding:

  • Store Currency: Choose from 10+ built-in presets (USD, EUR, GBP, PKR, INR, AED, SAR, CAD, AUD, etc.). Formatting and decimal places update throughout the entire application.
  • Minimum Delivery Order: Set the threshold (e.g. 500 or 25) required before a delivery order can be checked out.
  • Brand Header: Restaurant name displayed at the top of receipts.
  • Address & Phone: Two address lines and customer contact phone.
  • Payment & Bank Details: Print bank title and IBAN / mobile payment account details on the receipt footer for instant bank transfers.
  • Thank You Note: Custom footer message (e.g. "Follow us on Instagram @cheftech").

6.6 Kitchen Display System (KDS)

Press F8 on any terminal (or click Kitchen in the sidebar) to open the full-screen Kitchen Display System. Kitchen staff can:

  • View active tickets grouped by Dine-In, Takeaway, and Delivery.
  • See item quantities, item modifier notes, and order elapsed timers.
  • One-click mark orders as "Preparing" or "Ready".

6.7 Staff Roles & Security

Role Permissions
Owner / Admin Full system access: menu management, staff accounts, payroll, P&L reports, backup export/import, settings.
Manager Manage orders, process refunds, edit stock, manage suppliers and expenses, view sales analytics.
Cashier Open shift, take payments, hold orders, look up customers, print receipts, close shift.
Waiter Browse menu, add items to cart, assign tables, hold orders, send tickets to kitchen. Payment processing restricted.
Kitchen Access KDS screen only. View incoming orders and mark cooking progress.

  supabaseUrl: 'https://YOUR_PROJECT_ID.supabase.co',
  supabaseAnonKey: 'YOUR_SUPABASE_ANON_KEY',

  // Restaurant Branding

  restaurantPhone: '+1 (555) 019-2834',

7.2 Customer Ordering Experience

The customer website offers a fast, app-like ordering flow:

  • Category Filter: Instant category filtering with smooth scrolling (Burgers, Pizza, Appetizers, Drinks, Desserts).
  • Item Modifiers: Select sizes (Small, Medium, Large), preparation choices (Spicy, Mild), and add-on toppings.
  • Promo Codes: Enter discount coupons validated server-side by the consume-coupon Edge Function.
  • Loyalty Points: Returning customers can enter their phone number to redeem earned loyalty points for instant bill deductions.
  • Live Order Tracking: After placing an order, customers receive an order tracking link showing real-time updates (Pending → Preparing → Out for Delivery → Completed).

7.3 Real-Time POS Alert Chime

When a customer places an order on the website, the POS terminal immediately:

  1. Plays a high-priority audible notification chime.
  2. Displays a glowing badge on the "Online Orders" top bar button.
  3. Allows the cashier to accept the order with 1 click, automatically loading it into the kitchen queue and printing the delivery slip!

8. Production Deployment Guide

Deploying the POS Terminal

Build the production-ready static assets in cheftech-pos:

cd cheftech-pos
npm run build

The resulting dist/ folder contains static HTML, CSS, and JS files. You can host them anywhere:

  • Vercel / Netlify / Cloudflare Pages: Connect your Git repository or drag-and-drop the dist folder.
  • Local Network Server (Apache/Nginx/Caddy): Host it locally on a mini-PC or Raspberry Pi inside the restaurant so your terminals work even without an active internet connection!
  • PWA / Desktop App: Open the deployed URL in Chrome and click "Install ChefTech POS" to run it as a standalone full-screen window on your desktop.

Deploying the Online Ordering Website

The cheftech-website folder consists of static web assets. You can upload them directly via FTP/cPanel to any web hosting, or deploy via GitHub to Vercel/Netlify.

10. Troubleshooting & FAQs

Q: Why is Web Bluetooth not finding my printer?

Ensure you are using Google Chrome or Microsoft Edge on a supported operating system (Windows 10/11, macOS, Android, Linux). Web Bluetooth is not supported in Safari or Firefox. Also ensure your printer is powered on and not paired to another tablet or smartphone.

Q: Can I use ChefTech if my restaurant loses internet?

Yes, 100%! ChefTech POS stores all menu items, prices, open tabs, inventory, and completed sales locally in your browser's IndexedDB database. You can continue taking orders, printing receipts, and ringing up sales normally. When your internet reconnects, click the Sync button to push offline sales to Supabase.

Q: How do I change the default currency?

In the POS, click Printer & Settings (or the gear icon) → scroll to Currency & Regional Settings → select your preferred currency (e.g. USD, EUR, GBP, PKR, INR, AED). In the website, edit currencySymbol and currencyCode in config.js.

Q: How do I reset the Owner PIN if I forget it?

If logged in as Master Admin, go to Admin Settings → Owner PIN → enter a new PIN. For offline database resets, open your browser's Developer Tools (F12) → Application → IndexedDB → clear database, and the setup wizard will relaunch on next page load.
